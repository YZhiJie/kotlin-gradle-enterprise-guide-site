Kotlin & Gradle 企业级应用开发教程 ​

线上文档站：https://yzhijie.github.io/kotlin-gradle-enterprise-guide-site/（push 到 main 后由 GitHub Actions 自动构建并发布到公开部署仓）

一套面向企业级场景的 Kotlin 与 Gradle 全栈开发中文教程，覆盖语言基础、构建系统、JVM 后端、Android、性能安全、测试质量、CI/CD 与团队协作九大主题。

教程定位与适用人群 ​

本教程以 Kotlin 2.0 + Gradle 8.x（Kotlin DSL） 为技术基线，聚焦「能直接用于生产环境」的工程实践，而非语法手册式的罗列。每章包含概念解析、可运行代码示例、企业级场景分析、递进式实践任务与自测题。

零基础转行者有任意一门编程语言基础按章节顺序完整学习，完成全部实践任务

环境准备与验证 ​

推荐使用 SDKMAN! 管理 JVM 生态工具链（macOS / Linux）：

bash

curl -s "https://get.sdkman.io" | bash          # 安装 SDKMAN!
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 21.0.3-tem                      # 安装 Temurin JDK 21
sdk install kotlin                               # 安装最新稳定版 Kotlin
sdk install gradle 8.10                          # 安装 Gradle 8.x

代码约定说明 ​

本教程所有示例遵循以下约定（与第 9 章团队规范呼应）：

  1. 语言与标签：Kotlin/Kotlin DSL 用 ```kotlin，Groovy 用 ```groovy，TOML/YAML/bash 分别用对应标签；代码块首行注释标明文件名。
  2. 构建脚本：一律使用 Kotlin DSL（build.gradle.kts），Groovy DSL 仅作对比展示。
  3. 实践经验标注：⚠️ 表示坑点，✅ 表示推荐做法，❌ 表示反例。
  4. 运行方式：每个示例下方以「> 运行方式：」说明执行手段（kotlinc、kts 脚本、Gradle 任务或 IDE）。
  5. 命名：类用 UpperCamelCase，函数与变量用 lowerCamelCase，常量用 UPPER_SNAKE_CASE。
  6. 空安全优先：除非有明确理由，禁止使用 !!（详见第 1 章）。

如何使用本教程 ​

  • 每章开头有学习目标与核心知识点速览，可据此决定精读或跳读。
  • 企业级场景分析小节提炼自真实生产问题（高并发服务、大型 Android 团队、金融合规等），建议重点阅读。
  • 实践任务按 ★ 难度递进，建议全部动手完成；小结与自测用于检验掌握程度。
  • 章节之间通过首尾链接串联，支持顺序学习或按索引跳转。

常见问题（FAQ） ​

Q1：必须先学完第 2 章才能学 Gradle（第 3 章）吗？ 不必。第 3 章只要求 Kotlin 基础语法（第 1 章），但 build-logic 插件开发会用到第 2 章的 DSL 知识，可回头补读。

Q2：后端和 Android 两条线都要学吗？ 按需选择。第 4 章与第 5 章相互独立；但第 6~9 章为两条线共用，建议都读。

Q3：示例代码能直接用于生产吗？ 示例为教学裁剪版：演示机制但不包含完整异常处理与配置项，落地时请结合各章「企业级场景分析」小节的工程约束补全。

Q4：版本基线会过时吗？ 会。Kotlin/Gradle 演进很快，但空安全、结构化并发、构建生命周期、测试金字塔等核心思想长期稳定；升级时优先查阅官方迁移指南。

Q5：Windows 环境如何跟进？ SDKMAN! 仅支持 macOS/Linux；Windows 推荐 WSL2 使用 SDKMAN!，或用 IntelliJ IDEA 内置工具链管理，命令完全一致。
