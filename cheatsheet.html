空安全速查（1.4） ​

kotlin
user?.email?.length                       // 安全调用链：任一环 null -> null
user?.email?.length ?: 0                  // Elvis：null 给默认值
?: return                                  // Elvis 提前返回
?: throw IllegalStateException("缺字段")    // Elvis 抛异常
user!!.email                              // 非空断言：null 即 NPE（生产代码禁用）
any as? String ?: ""                      // 安全转换：失败返回 null
user?.let { work(it) } ?: fallback()      // 非空才执行 + 缺失分支
lateinit var dep: Service                 // 构造后初始化优于 !!

协程异常处理决策表（2.3） ​

抛出位置异常行为正确处理点
launch立即沿 Job 树上抛，取消兄弟边界 CoroutineExceptionHandler 兜底
async（普通 Job 子协程）封装进 Deferred，父作用域仍取消runCatching { await() }
async（SupervisorJob 直接子级）仅 await() 时抛await 处降级
Flow 上游沿流向下传播.catch{}（只接其上游，须位于下游）
collect{} 内catch 管不到collect 内 try-catch
kotlin
val handler = CoroutineExceptionHandler { _, e -> log.report(e) }  // 只上报，不写业务恢复
flow.map{}.catch { e -> emit(fallback) }.collect { }
runCatching { deferred.await() }.getOrElse { default }              // 业务降级在 await

fun printAny(list: List<*>) { }                     // 星投影：只读、元素类型未知
fun fill(sink: MutableList<in Number>) { }          // 使用处逆变投影
