第二部 · 精通专题 D1–D12 ​

  • D12 版本策略与内容维护：版本单一事实来源、双轨版本、季度升级、锚点与编译校验。
  • D1 Gradle 精通：Provider/Property API、BuildService、Worker API、TestKit、远程构建缓存。
  • D2 协程与 Flow 深水区：背压策略、并发限流、取消与清理、回调适配、Java/Reactor 互操作、虚拟线程选型。
  • D3 生产可观测性：Actuator/Micrometer/OTel、trace 跨 HTTP/协程传播、MDC 搬运、标签基数治理、SLO 与错误预算。
  • D4 Android 多模块与变体：api/impl 拆分、约定插件、边界强制校验、变体矩阵、Room 迁移、DataStore 与 Koin 装配。
  • D5 性能剖析方法论：JFR 火焰图、分配与锁竞争、heap dump 泄漏定位、thread dump 死锁、JMH 基线，以及 Perfetto/JankStats/Macrobenchmark。
  • D6 测试工程化：test suite 分层、test fixtures、Testcontainers、ArchUnit、PIT 变异测试、覆盖率门禁、flaky 隔离、分片并行与 Pact 提供方验证。
  • D7 CI 增量与缓存：path filter + 受影响模块矩阵 + 任务缓存三层增量、复用工作流与 concurrency、缓存键与命中率度量、semantic-release 发布自动化。
  • D8 企业级参考工程：订单创建/查询/分页/取消闭环、Flyway 迁移、事务与幂等、JWT 接口级鉴权、RFC 7807 统一错误、健康检查与优雅停机、一键启动。
  • D9 KMP 与 Compose Multiplatform：shared 领域/序列化/网络边界、expect/actual、Compose Android + Desktop 跑通、iOS 编译与补齐步骤。
  • D10 服务端安全与供应链：接口级认证授权、OWASP API Security Top 10、密钥轮换、传输与存储边界、SBOM、OSV 高危门禁、依赖校验与镜像扫描。
  • D11 消息驱动与一致性：事务性 Outbox、至少一次投递、幂等消费、退避与死信、重放接口、故障注入测试、Kafka 降级形态。
  • 执行状态与已知降级见 ROADMAP-mastery.md。
